# habit-pet-ai
1. 项目介绍
AI 习惯养成宠物：本项目是一款趣味线上养成宠物微信小程序，（前期微信小程序验证用户需求，后再有针对性开发APP）。依托后端服务与服务器部署搭建而成，面向青少年、学生及年轻日常休闲用户群体。项目包含宠物饲养成长、互动玩乐、状态记录、日常任务、趣味互动等核心功能模块，搭配后台数据管理、消息推送、权限管控与运维保障体系。 项目切实解决大众碎片化时间无处消遣、日常缺乏趣味陪伴、闲暇生活单调乏味的痛点，同时满足用户轻松解压、休闲娱乐、线上趣味陪伴的需求。整体部署于云服务器，借助 PM2 进程工具保障程序稳定后台运行，搭配域名解析与安全校验实现正常访问。 产品操作简单易上手，以轻量化养成玩法为主，无需高额时间精力投入，贴合碎片化使用习惯，既能填补空闲时光，也可提供情绪陪伴，后续可接入广告资源实现商业变现。
